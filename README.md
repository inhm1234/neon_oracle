# 오늘의 운세코드

AI 운세 분석 웹사이트 개발 버전입니다.

## 현재 버전

V3-13.1 test

## 이전 안정 버전

V3-12 stable

## 핵심 기능

- 생년월일 / 태어난 시간 기반 오늘의 운세 분석
- Google 로그인 / 로그아웃
- 로그인 사용자 기본 정보 자동 입력 / 자동 저장
- Firestore 서버 저장 / 불러오기
- 관리자 전용 통계 대시보드
- 일반 사용자 화면과 관리자 도구 분리
- 루미 / 모코 / 노바 파트너 시스템
- 출석 보상 / 연속 출석 / 보상 기록
- 파트너 도감 / 프로필 화면
- 이전 운세 다시보기
- 내 데이터 관리 / 백업 파일 다운로드 / 백업 파일 불러오기
- 검색 유입 기본 세팅 / SEO 메타 태그 / sitemap.xml / robots.txt

## V3-13.1 추가 기능

- V3-13 test의 수동 저장 버튼 중심 흐름을 자동 저장 흐름으로 수정
- Google 로그인 후 계정에 저장된 기본 정보가 있으면 입력칸에 자동 반영
- 운세 분석을 실행하면 현재 입력값을 기본 정보로 자동 저장
- 로그인 전에는 현재 브라우저에 자동 저장
- Google 로그인 상태에서는 Firestore 계정 기본 정보에도 자동 저장
- 틀린 정보가 있으면 입력칸에서 수정 후 다시 운세 분석하면 자동 갱신
- 일반 사용자 화면을 복잡하게 만들지 않도록 수동 저장/불러오기 버튼 제거
- 저장 정보 삭제 버튼만 유지
- V3-12의 SEO / 관리자 분리 / 기존 기능 유지

## 적용 방법

## 확인 체크리스트

- 일반 주소에서 첫 화면이 심플하게 유지되는지 확인
- 첫 화면의 내 기본 정보 카드가 자동 저장 안내 문구로 보이는지 확인
- 수동 저장 / 불러오기 버튼이 보이지 않는지 확인
- 이름 / 성별 / 생년월일 / 태어난 시간을 입력하고 운세 분석하기
- 새로고침 후 입력칸에 기본 정보가 자동으로 들어오는지 확인
- 내용을 수정하고 다시 운세 분석하면 수정 내용이 유지되는지 확인
- Google 로그인 후 저장된 기본 정보가 자동으로 입력되는지 확인
- 운세 분석 버튼이 기존처럼 작동하는지 확인
- 일반 주소에서 관리자 도구가 보이지 않는지 확인
- `?admin=1` 주소에서 관리자 도구와 통계 대시보드가 보이는지 확인
