# 오늘의 운세코드

AI 운세 분석 웹사이트 개발 버전입니다.

## 현재 버전

V3-14.3.4 test

## 이전 안정 버전

V3-12 stable

## 핵심 기능

- 생년월일 / 태어난 시간 기반 오늘의 운세 분석
- Google 로그인 / 로그아웃
- 로그인 사용자 기본 정보 자동 입력 / 자동 저장
- Firestore 서버 저장 / 불러오기
- 관리자 전용 통계 대시보드
- 일반 사용자 화면과 관리자 도구 분리
- 루미 / 모코 / 노바 파트너 시스템
- 출석 보상 / 연속 출석 / 보상 기록
- 파트너 도감 / 프로필 화면
- 이전 운세 다시보기
- 내 데이터 관리 / 백업 파일 다운로드 / 백업 파일 불러오기
- 검색 유입 기본 세팅 / SEO 메타 태그 / sitemap.xml / robots.txt

## 확인 체크리스트

- 일반 주소에서 첫 화면이 운세 입력 중심으로 단순하게 보이는지 확인
- 첫 방문자는 안내 카드가 입력 영역 위에 자연스럽게 보이는지 확인
- 로그인했거나 기존 기록이 있는 재방문자는 첫 방문자 안내 카드가 숨겨지는지 확인
- 바로 입력하러 가기 버튼을 누르면 입력 영역으로 이동하는지 확인
- 캐릭터/파트너 오라클이 화면에 항상 보이는지 확인
- PC 화면에서 캐릭터가 한 위치에서 잠깐 행동하다가 천천히 이동하는지 확인
- 가만히 있기 / 걷기 / 날기 / 잠자기 / 뒤돌기 / 눕기 같은 포즈가 자연스럽게 보이는지 확인
- 모바일에서는 캐릭터가 입력을 방해하지 않고 하단에 유지되는지 확인
- 입력칸을 누르면 캐릭터 말풍선이 바뀌는지 확인
- 이름 / 성별 / 생년월일 / 태어난 시간을 입력하고 운세 분석하기
- 운세 분석 중 캐릭터가 분석 중 말풍선으로 바뀌는지 확인
- 결과 화면 상단에 “파트너가 읽어주는 오늘의 운세”가 보이는지 확인
- 결과 화면에 공유용 큰 카드가 사라지고 작은 버튼만 남았는지 확인
- 공유하기 버튼이 공유창 또는 문구 복사로 작동하는지 확인
- 결과 화면 하단의 파트너 / 기록 버튼을 누르면 해당 영역이 열리고 이동되는지 확인
- 새로고침 후 입력칸에 기본 정보가 자동으로 들어오는지 확인
- Google 로그인 후 저장된 기본 정보가 자동으로 입력되는지 확인
- 일반 주소에서 관리자 도구가 보이지 않는지 확인
- `?admin=1` 주소에서 관리자 도구와 통계 대시보드가 보이는지 확인
