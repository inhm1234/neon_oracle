# 오늘의 운세코드

생년월일과 오늘 날짜를 바탕으로 오늘의 흐름을 가볍게 돌아보는 무료 감성 운세카드 테스트 버전입니다.

## 현재 버전

V3-15.4 test

## 이전 안정 버전

V3-14 stable

## 핵심 기능

- 생년월일 / 태어난 시간 기반 오늘의 운세 분석
- Google 로그인 / 로그아웃
- 로그인 사용자 기본 정보 자동 입력 / 자동 저장
- Firestore 서버 저장 / 불러오기
- 관리자 전용 통계 대시보드
- 일반 사용자 화면과 관리자 도구 분리
- 루미 / 모코 / 노바 파트너 시스템
- 출석 보상 / 연속 출석 / 보상 기록
- 파트너 도감 / 프로필 화면
- 이전 운세 다시보기
- 내 데이터 관리 / 백업 파일 다운로드 / 백업 파일 불러오기
- 검색 유입 기본 세팅 / SEO 메타 태그 / sitemap.xml / robots.txt




## V3-15.4 test 정리

- 10명에게 먼저 보여주는 공개 테스트를 기준으로 첫 화면 문구를 부드럽게 정리
- 정통 사주/전문 상담이 아니라 재미와 자기기록용 감성 리포트라는 안내를 강화
- 결과 화면 아래에 무료 운영 안내, 광고 자리 준비중, 후원 버튼 준비중, 10명 피드백 우선 문구 추가
- 유료 운세 판매가 아니라 무료 경험, 공유, 후원, 광고 중심으로 운영한다는 방향을 화면에 반영
- app.js 내부 `DEV_VERSION`을 V3-15.4 test로 맞춰 문서/화면/내부 버전 불일치 수정

- “정통 사주 완벽 분석”이라고 과장하지 않고, 생년월일과 오늘 날짜 흐름을 코드화한 간이 리포트라는 포지션을 유지합니다.
