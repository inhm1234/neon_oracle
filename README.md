# 오늘의 운세코드

AI 운세 분석 웹사이트 개발 버전입니다.

## 현재 버전

V3-13 test

## 이전 안정 버전

V3-12 stable

## 핵심 기능

- 생년월일 / 태어난 시간 기반 오늘의 운세 분석
- Google 로그인 / 로그아웃
- 로그인 사용자 기본 정보 자동 입력 / 저장 / 불러오기
- 카카오톡 등 앱 내부 브라우저 접속 안내
- 모바일 리다이렉트 로그인
- Firestore 서버 저장 / 불러오기
- 관리자 전용 통계 대시보드
- 일반 사용자 화면과 관리자 도구 분리
- 루미 / 모코 / 노바 파트너 시스템
- 출석 보상 / 연속 출석 / 보상 기록
- 파트너 도감 / 프로필 화면
- 이전 운세 다시보기
- 내 데이터 관리 / 백업 파일 다운로드 / 백업 파일 불러오기

## V3-13 test 추가 기능

- 운세 입력 영역 안에 `내 기본 정보` 작은 카드 추가
- 이름 또는 닉네임 / 성별 / 생년월일 / 태어난 시간을 기본 정보로 저장
- 저장된 기본 정보를 다음 접속 시 자동으로 입력칸에 반영
- 사용자가 입력칸에서 내용을 수정한 뒤 `현재 입력값 저장`을 누르면 다시 저장
- 로그인 전에는 현재 브라우저에 저장
- Google 로그인 상태에서는 Firestore 사용자 문서에도 저장
- 저장 정보 불러오기 / 삭제 버튼 추가
- V3-12의 검색 유입 기본 세팅과 일반 사용자 / 관리자 화면 분리 구조 유지

## 확인 체크리스트

- 일반 주소에서 첫 화면이 심플하게 유지되는지 확인
- 운세 입력 영역 안에 `내 기본 정보` 카드가 작게 보이는지 확인
- 이름 / 성별 / 생년월일 / 태어난 시간을 입력하고 `현재 입력값 저장`을 눌렀을 때 저장되는지 확인
- 새로고침 후 저장된 기본 정보가 자동으로 입력되는지 확인
- 입력칸 내용을 수정한 뒤 다시 저장하면 수정 내용이 반영되는지 확인
- Google 로그인 후 기본 정보 저장이 정상 안내되는지 확인
- 운세 분석 버튼이 정상 작동하는지 확인
- 일반 주소에서 관리자 도구가 보이지 않는지 확인
- `?admin=1` 주소에서 관리자 도구와 통계 대시보드가 보이는지 확인
- 파트너 / 출석 / 이전 운세 / 도감 기능이 그대로 작동하는지 확인
